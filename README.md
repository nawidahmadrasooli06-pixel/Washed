# ربات «آخرین واژه» — تیم کاکتوس 🌵
ربات بازی گروهی برای «گروه چتکده هراتی‌ها» با پنل خصوصی مالک.

> ⚠️ **صادقانه:** منطق بازی با ۴۹ تست خودکار آزمایش شده، اما این ربات **در تلگرام واقعی و گروه واقعی آزمایش نشده** (در محیط ساخت، اینترنت/تلگرام نبود). لایه‌ی تلگرام فقط با «تلگرام جعلی» تست شد. بعد از راه‌اندازی، یک بازی آزمایشی کوتاه با چند نفر بزن.

## ساختار فایل‌ها (همه را در GitHub بگذار)
```
bot.py            نقطه‌ی شروع
config.py         خواندن Environment Variables
database.py       دیتابیس SQLite و مهاجرت نسخه
game_engine.py    منطق بازی (جواب، تایمر، دور، قلب، فینال)
answers.py        نرمال‌سازی و تشخیص جواب
topics.py         موضوعات و بانک واژه‌ها
players.py        بازیکنان و قلب‌ها
prizes.py         جایزه‌ها
banner.py         ساخت بنر
commands.py       تشخیص دستورهای فارسی
controller.py     اتصال دستورها/دکمه‌ها به بازی
keyboards.py      دکمه‌های شیشه‌ای
handlers.py       لایه‌ی تلگرام (پیام، دکمه، بنر پین‌شده، تایمر)
texts.py          متن راهنماها
data/topics.json  بانک ۱۰ موضوع
tools/            ساخت بانک (bank_src.py, build_topics.py)
tests/            تست‌ها
requirements.txt  .env.example  .gitignore  render.yaml  README.md
COMMANDS.md  commands_to_copy.txt
```

## ۱) BotFather (تنظیم ربات)
1. در تلگرام به @BotFather برو، `/newbot` بزن و توکن بگیر (آن را به کسی نده و در GitHub نگذار).
2. **Privacy Mode:** `/setprivacy` ← ربات را انتخاب کن ← **Disable**.
   (بدون این، ربات پیام‌های عادی بازیکن‌ها را در گروه نمی‌بیند.)
   راه دوم: ربات را در گروه **ادمین** کن (ادمین همه‌ی پیام‌ها را می‌بیند).
3. اگر قبلاً ربات را به گروه اضافه کرده بودی، بعد از تغییر Privacy Mode، ربات را از گروه حذف و دوباره اضافه کن.

## ۲) GitHub
1. در github.com یک مخزن (Repository) **Private** بساز.
2. همه‌ی فایل‌های این پروژه را آپلود کن (Add file ← Upload files). فایل `.env` واقعی یا توکن را آپلود نکن.

## ۳) Render
1. render.com ← New ← **Web Service** ← به مخزن GitHub وصل کن.
2. Runtime: Python 3 — Build: `pip install -r requirements.txt` — Start: `python bot.py`
3. **Environment Variables** (Environment):
   - `BOT_TOKEN` = توکن ربات
   - `OWNER_ID` = `8659480577`
   - `DB_PATH` = `/var/data/last_word.db`
   - `GROUP_CHAT_ID` = (بعداً، مرحله‌ی ۵)
4. **Persistent Disk:** در همان سرویس، بخش Disks ← Add Disk — Mount Path: `/var/data`، حجم ۱ گیگ.
   - Persistent Disk فقط روی پلن‌های **پولی** Render هست. بدون دیسک، هر ری‌استارت همه‌ی داده‌ها (واژه‌هایی که تأیید کردی، بازی جاری) پاک می‌شود.
   - می‌توانی به‌جای ساخت دستی، فایل `render.yaml` را با Blueprint استفاده کنی.
5. Deploy کن؛ در Logs باید ببینی: «ربات بالا آمد».

## ۴) افزودن ربات به گروه
1. ربات را به گروه اضافه کن و **ادمین** کن با این مجوزها: ارسال پیام، ویرایش پیام‌ها (خودش)، **پین کردن پیام‌ها**.
2. ربات به پیوی تو پیام می‌دهد: «به گروه اضافه شدم، شناسه: …».

## ۵) شناسه‌ی عددی گروه
- داخل گروه (با اکانت مالک) بنویس: `ثبت گروه` — ربات شناسه را ذخیره و نمایش می‌دهد (منفی و بلند، مثل `-100123…`).
- برای دائمی بودن، همین عدد را در Render به‌عنوان `GROUP_CHAT_ID` بگذار.
- نکته: `@Group_Herat_Afghan` جایگزین مطمئن شناسه‌ی عددی نیست.

## ۶) اجرا و شروع بازی
1. به پیوی ربات برو، `/start` بزن ← پنل می‌آید.
2. «🎮 شروع بازی جدید» ← موضوع ← نام بازیکن‌ها (هر نام یک خط) ← تعداد قلب ← جایزه‌ها (اختیاری) ← تأیید.
3. بنر در گروه ساخته و پین می‌شود. بازیکن‌ها واژه می‌گویند.
4. **تشخیص بازیکن:** ربات فرستنده را از روی نام تلگرامش با نام ثبت‌شده تطبیق می‌دهد. اگر نشناخت، روی پیام آن بازیکن ریپلای بزن: `ربط نوید`.

## ۷) پاک‌سازی بعد از بازی
پنل ← «🧹 پاک‌سازی بازیکنان» ← دو بار تأیید. بازیکن‌ها، قلب‌ها، تاریخچه و تایمر پاک می‌شود؛ موضوع‌ها، بانک واژه‌ها، مترادف‌ها، جواب‌های تأییدشده، بنر و جایزه‌ها می‌مانند.

## قوانین تصمیم‌گرفته‌شده (چون در متن مبهم بود)
- حداقل ۳ بازیکن برای شروع.
- جواب ناشناخته: تایمر تا تصمیم مالک می‌ایستد؛ «قبول» = ثبت به‌عنوان جواب همان بازیکن و شروع دوباره‌ی تایمر؛ «رد» = تایمر از همان‌جا ادامه.
- برنده‌ی دور نمی‌تواند خودش را برای کسر قلب انتخاب کند. اگر انتخاب نکرد، ربات خودسرانه کسی را انتخاب نمی‌کند؛ مالک می‌تواند با دکمه یا `انتخاب نام` انتخاب کند.
- با ۲ نفر باقی‌مانده: قلب بیشتر = رتبه‌ی بالاتر؛ قلب مساوی = «دور تعیین تکلیف» (برنده‌ی آن دور رتبه‌ی اول).
- ۳ ثانیه مکث قبل از شمارش؛ تحمل ۰٫۷ ثانیه برای تأخیر شبکه.
- جایزه‌ها با پاک‌سازی پاک نمی‌شوند (مالک می‌تواند عوضشان کند).
